# Plans

Historical design notes captured **before** features were implemented.

## What this is (and isn't)
- This is **not documentation**. Once a feature is shipped, its behavior lives in
  `README.md`; the plan here is kept only for historical reference.
- These are intentionally allowed to go **stale**. There is no maintenance
  obligation — they exist so future work can learn how earlier decisions were made.
